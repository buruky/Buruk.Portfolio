## Mood (images in this folder)

| File | What it's for |
| --- | --- |
| `mood-sza-ctrl-cover.png`, `mood-crt-monitors-grass.png` | The calm base mood: old tech in long grass, golden light, film grain, faded greens and beige. Nostalgic and personal. |
| `mood-spiderverse-city-concept.png` | A hand-inked city soaked in its own culture: clashing colour, misprinted offsets. Idea: Asmara drawn this way as the origin world. |
| `mood-spiderverse-miles-swing.png` | RGB split, halftone dots. The toolkit for glitch and "travel" moments. |
| `mood-spiderverse-leap-of-faith.png` | Upside-down violet city, one figure falling. Idea: the story's turning point (taking on the double major). |
| `about-flow-august.png` | The About flow: giant heading, floating photos, a line winding through numbered steps. |

Sonic Colors: use only the *feeling* (speed, bright playful energy). Nothing should read as Sonic.
